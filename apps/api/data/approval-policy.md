## 1. Purpose

This policy explains how operators review content submitted for approval on the
site patrol platform: onboarding folders, patrol videos, equipment documents and
site maps. Every item must be reviewed before it is published to field teams.

## 2. Priority by category

Each item gets a default priority from its category. If an item has its own
priority set by the submitter, that priority overrides this table.

| Category   | Default priority | Why                                                              |
| ---------- | ---------------- | ---------------------------------------------------------------- |
| safety     | high             | Safety equipment and sensor specs protect people on site.        |
| onboarding | medium           | New patrol staff cannot start until their checklists are approved. |
| training   | medium           | Training videos guide patrols but do not block daily work.       |
| mapping    | low              | Zone layouts and camera maps change rarely and can wait.         |

When two items have the same priority, review the oldest one first.

## 3. How to review an item

1. Open the item and check the title and location are correct.
2. Open the file itself: watch the video, read the PDF, or view the image.
3. Compare the content with this policy and with current site rules.
4. Approve it, or reject it with a clear reason.
5. Add a short note so the submitter knows what happens next.

## 4. When to reject

Reject an item if the file is missing or will not open, if it shows outdated
equipment or procedures, if a map does not match the real camera positions, or
if personal data of staff or visitors is visible. Always give the reason.

## 5. Urgent items and escalation

A submitter may mark an item as urgent, for example when cameras are offline or
a safety rule has changed. Urgent items are reviewed before everything else. If
an urgent item cannot be reviewed within one working day, escalate it to the
site supervisor.
